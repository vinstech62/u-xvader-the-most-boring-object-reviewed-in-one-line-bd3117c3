One funny, true line reviewing the most boring everyday object we could
name — the kitchen sponge. It soaks up everyone else's mess, smells like
a crime scene by Friday, and still shows up for work on Monday.

## Run it

```sh
python3 main.py
```

Writes exactly one line (117 characters) to `/output/entry.txt`.
Deterministic: the same line on every run. Python 3 standard library only,
no network, no randomness.
